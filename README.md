# VRCSmartphoneSender v0.1

WindowsのVRChatへ、スマホのブラウザから文章を送るアプリです。PCのクリップボードへのコピーにも対応します。

## 初回準備
1. ZIPをすべて展開し、`VRCSmartphoneSender.exe` をダブルクリックします。exe版はPythonのインストール不要です。
2. ソース版を使う場合はPython 3.11以降をインストールし、`setup.bat`、`start.bat` の順にダブルクリックします。
3. exeを作り直す場合は `build_exe.bat` を実行します。Pythonとインターネット接続が必要です。
4. Windowsのファイアウォールが表示されたら、自宅の「プライベートネットワーク」で通信を許可します。
5. スマホをPCと同じWi-Fiにつなぎ、PCアプリのQRコードをカメラで読み取ります。
6. VRChatのアクションメニュー → Options → OSC → Enabled をONにします。
7. 文章を入力し、「チャットボックスに送信」「クリップボードに送信」を選んで「送信」を押します。両方ともオンにすると、PCへコピーしたあとVRChatへ送ります。

PCへコピーした文章は、PC上の任意のアプリで Ctrl+V で貼り付けられます。自動貼り付けはしません。既存のクリップボード内容は上書きされます。PCのクリップボードをスマホから読む機能はありません。

## 定型文の編集
- `presets.txt` をメモ帳などで開き、UTF-8で保存してください。
- 1行が1つの定型文になります。空行は表示されません。
- 編集後にPCアプリを再起動し、スマートフォンの画面を開き直すと反映されます。
- exe版でも `VRCSmartphoneSender.exe` と `presets.txt` を同じフォルダーに置いてください。

## 接続できない場合
- PCが有線LAN、スマホがWi-Fiでも同じLANなら利用できます。
- IP選択で192.168.x.x / 10.x.x.x等の自宅LAN側アドレスを選んでください。127.0.0.1はPC内確認専用です。VPN・仮想アダプターのIPは避けてください。
- ゲストWi-FiやAPの端末間通信禁止設定では接続できません。
- PCのネットワークがプライベートになっていること、Pythonの受信TCP 8765がプライベートネットワークで許可されていることを確認してください。ファイアウォールを丸ごと無効にする必要はありません。
- 再起動すると接続キーが変わります。QRコードを読み直してください。
- OSCの送信先はPC内のUDP 9000固定です。VRChatの起動オプションで変更している場合は標準設定に戻してください。
- 「OSC送信しました」はUDP送信の完了であり、VRChatでの表示確認ではありません。OSC有効化、チャットボックス表示設定、VRChat側の送信制限を確認してください。

## 制限と取り扱い
- VRChat向けは144 UTF-16コード単位・明示改行9行までで検証します。絵文字は2文字以上として数える場合があります。自動折り返しによる9行超過は事前に判定できません。
- アプリ側でVRChatへの送信間隔を最低1.5秒にしています。VRChat自身の制限は別途適用されます。
- 長文は切り捨てずエラーにします。PCコピーのみはUTF-8で約60KBまで可能です。
- PCアプリを起動している間だけ動作します。PCのスリープ中は使えません。
- 接続用URL/QRコードを知っている端末は送信・クリップボードの上書きができます。他人に共有しないでください。
- 通信はローカルHTTPです。信頼できる自宅LANで使用してください。ポート開放やインターネット公開は不要です。
- 文章は外部サービスへ送信しません。ブラウザの履歴ボタン用の文章はメモリー内に最大10件のみ保持し、ディスクに保存しません。
- 「両方」はPCコピー後にOSC送信します。OSC送信に失敗してもコピーは元に戻しません。
- Python不要の `VRCSmartphoneSender.exe` と、従来のPythonソース・bat起動の両方を同梱しています。

## 開発者向け
標準ライブラリでHTTP/OSCを処理し、TkのメインスレッドでWindowsのクリップボードを書き換えます。QRコードだけqrcode/Pillowを使用します。
`python -m unittest discover -s tests -v` でHTTP認証・UTF-8 OSC・文字数検証・UDP送信を検証できます。
Windows実機およびVRChatとの接続は利用環境での確認が必要です。

VRChat公式仕様: https://docs.vrchat.com/docs/osc-as-input-controller
